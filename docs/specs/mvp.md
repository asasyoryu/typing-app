# 返信打 MVP 仕様

IT エンジニアのチャット返信を模した、ブラウザ向けタイピングゲーム。

## 体験

相手からメッセージが届き、決められた返信文をローマ字で打って送信する。  
1件送るたびに給料が加算され、プレイ終了時の合計が **ゲーム内年収** になる。

```
タイトル → 難易度選択 → プレイ（90秒） → 結果 → （任意）分析
```

- タイトルから分析へ直接行ける
- 結果から「もう一度」「分析」「タイトル」へ進める

## ルール

- 制限時間は全難易度 **90秒**
- 日本語は画面上は漢字かな、入力はローマ字
- 英数字・記号・メンション・Markdown は見える文字をそのまま打つ
- ローマ字のゆれ（`si`/`shi` など）は一般的な範囲で受理する
- ミスしても位置は進まない。ミス数と正確性に反映する
- 全文一致で自動送信
- プレイ中のキー入力はブラウザ内だけで集計し、終了時にまとめて保存する

## スコア

```
獲得額 = 基礎額 × 速度ボーナス × 正確性ボーナス
```

| 難易度       | 肩書                 | 1通の基礎額目安 |
| ------------ | -------------------- | --------------- |
| beginner     | 新米エンジニア       | 8〜15 万円      |
| intermediate | 慣れてきたエンジニア | 15〜28 万円     |
| advanced     | つよつよエンジニア   | 25〜45 万円     |

結果に出すサブ情報: 入力速度、正確性、ミス数、最大連続入力数。

## 世界観

- 社名: 株式会社トラブルベース
- 主人公はカタカナ語が好きで、返信に必ず1つ冗談を入れる
- UI は Color Thread（白ベース、余白多め、ビビッドな色面、スレッドと入力欄が主役）

## データ

- 初回アクセスで匿名 ID をブラウザに保存する。ログインは作らない
- 個人情報は保存しない
- D1 にタイピング問題とプレイ結果を置く
- 分析は苦手キー / 指 / 2キー遷移。通算を分析画面に出す
