# MVP Acceptance Checklist

実装完了前に、この一覧をすべて満たすこと。

## プロダクト

- [ ] タイトルで世界観と 3 難易度（新米 / 慣れてきた人 / つよつよ）が見える
- [ ] 難易度を選んで 90 秒プレイを開始できる
- [ ] Slack 風スレッドで相手メッセージと自分の返信が表示される
- [ ] 返信はローマ字入力。全文一致で自動送信される
- [ ] `si`/`shi` など一般的なローマ字のゆれを受け付ける
- [ ] ミスしても入力位置は進まず、ミス数が増える
- [ ] 送信のたびに年収が加算され、累計が見える
- [ ] 時間切れで結果画面に移る
- [ ] 結果に年収・速度・正確性・ミス数・最大連続入力数が出る
- [ ] 分析画面で苦手キー・指・2キー遷移の通算が見える
- [ ] 各難易度に 15 問以上ある
- [ ] 題材が仕様の世界観に沿っている（カタカナ + 1ボケ、URL なし）

## データと API

- [ ] 初回アクセスで匿名 ID がブラウザに保存される
- [ ] プレイ中にキー入力をサーバへ送らない
- [ ] 終了時だけプレイ結果を保存する
- [ ] 個人情報を保存しない
- [ ] 問題と結果が D1 にある
- [ ] ローカル D1 と本番 D1 が分かれている
- [ ] D1 変更が migration で管理されている
- [ ] 問題データの投入手段がある（just 経由）

## 開発基盤

- [ ] React / TypeScript / Vite+ / Hono が 1 Worker 構成
- [ ] Nix + direnv で開発環境を入れる
- [ ] `just dev` / `just check` / `just deploy` / `just db-migrate` がある
- [ ] `just check` が lint・typecheck・test・build を行う
- [ ] GitHub リポジトリ `asasyoryu/typing-app` が public
- [ ] Cloudflare Workers にデプロイされ、URL でプレイできる
