# MVP Acceptance Checklist

実装完了前に、この一覧をすべて満たすこと。

## プロダクト

- [x] タイトルで世界観と 3 難易度（新米 / 慣れてきた人 / つよつよ）が見える
- [x] 難易度を選んで 90 秒プレイを開始できる
- [x] Slack 風スレッドで相手メッセージと自分の返信が表示される
- [x] 返信はローマ字入力。全文一致で自動送信される
- [x] `si`/`shi` など一般的なローマ字のゆれを受け付ける
- [x] ミスしても入力位置は進まず、ミス数が増える
- [x] 送信のたびに年収が加算され、累計が見える
- [x] 時間切れで結果画面に移る
- [x] 結果に年収・速度・正確性・ミス数・最大連続入力数が出る
- [x] 分析画面で苦手キー・指・2キー遷移の通算が見える
- [x] 各難易度に 15 問以上ある
- [x] 題材が仕様の世界観に沿っている（カタカナ + 1ボケ、URL なし）

## データと API

- [x] 初回アクセスで匿名 ID がブラウザに保存される
- [x] プレイ中にキー入力をサーバへ送らない
- [x] 終了時だけプレイ結果を保存する
- [x] 個人情報を保存しない
- [x] 問題と結果が D1 にある
- [x] ローカル D1 と本番 D1 が分かれている
- [x] D1 変更が migration で管理されている
- [x] 問題データの投入手段がある（just 経由）

## 開発基盤

- [x] React / TypeScript / Vite+ / Hono が 1 Worker 構成
- [x] Nix + direnv で開発環境を入れる
- [x] `just dev` / `just check` / `just deploy` / `just db-migrate` がある
- [x] `just check` が lint / typecheck / test / build を行う
- [x] GitHub リポジトリ `asasyoryu/typing-app` が public
- [x] Cloudflare Workers にデプロイされ、URL でプレイできる
